## Proyecto destacado

### Agenda e Inventarios Inteligentes

Proyecto académico en Java para gestionar citas médicas, pacientes e inventario hospitalario usando estructuras de datos, algoritmos de búsqueda, algoritmos de ordenamiento y datasets CSV.

**Tecnologías:** Java 21, Maven, Apache Commons CSV, JUnit 5

**Conceptos aplicados:**

- Programación orientada a objetos
- Arreglos y listas simplemente enlazadas
- Bubble Sort, Selection Sort e Insertion Sort
- Búsqueda secuencial, búsqueda con centinela y búsqueda binaria
- Lectura de datasets CSV
- Análisis de casos borde

🔗 Repositorio: [AgendaInventarioInteligentes](https://github.com/AlejandroTatum/AgendaInventarioInteligentes)
